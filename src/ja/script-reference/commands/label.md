# label

ラベルを設定します。
詳しくは[ラベルジャンプ](../../webgal-script/scenes.md#ラベルジャンプ)を参照してください。

## ステートメント内容

ラベル名を指定します。このコマンド自体は何も実行しませんが、`choose` や `jumpLabel` と組み合わせて使用できます。

``` webgal
label:myLabel;
```

各ラベルは 1 つのシーンファイル内で **1 回だけ** 定義できます。ただし、異なるシーンファイルでは同じラベル名を使用できます。

同じシーンファイル内に同名ラベルが複数定義されている場合、`choose` や `jumpLabel` などのコマンドはシーンファイルの先頭から下方向に検索し、最初に条件に一致したラベル位置へジャンプします。
